# Шаблон «Tech workspace»

Reference для категории **«Дом и интерьер»** (`cat_home`). Шаблон `tpl_home_lifestyle` создан миграцией `010` с порядком `30`. Миграция `052-home-lifestyle-template` добавляет reference и общий recipe, `053-home-lifestyle-variants` — десять сценариев серии. Название «Tech workspace» задано для этого слота по запросу, хотя визуальный сюжет — кухонная предметная сцена.

Reference уменьшен из предоставленного JPG до размера каталога и сохранён в WebP; исходный JPG в каталог шаблона не помещён. Изображение показывает нож на тёмной фактурной кухонной поверхности, со свободным полем для крупного заголовка, коротких тезисов и акцентной плашки. Салат, травы, специи и клетчатая салфетка остаются декоративным окружением, если оно подходит товару пользователя; для других товаров используется нейтральная тёмная домашняя поверхность.

## Подключение

1. **До применения миграций** загрузить WebP в bucket приложения по точному ключу `templates/tpl_home_lifestyle/6fc562dc-410d-419d-bcad-766ab3a5357d.webp` с Content-Type `image/webp`. В ключ не входят имя bucket и префикс `assets/`.
2. Запустить приложение с Liquibase: миграция `052` обновит шаблон и добавит asset, миграция `053` — десять сценариев. Обе должны быть подключены в master changelog после предыдущих миграций каталога.
3. Открыть категорию «Дом и интерьер» или вызвать `GET /api/v1/templates?categoryId=cat_home` для просмотра превью.

Нож и его надписи служат демонстрацией композиции. При генерации его заменяет товар пользователя с сохранением формы, цвета, бренда и видимой маркировки. Заявления «идеально острый», «удобная ручка», количество «1 шт» и любые другие свойства ножа не переносятся на новый товар. Заголовок и текстовые блоки заполняются только подтверждёнными данными; неподтверждённые блоки опускаются. Тёмная палитра относится к фону и графике, но не меняет цвет товара.
