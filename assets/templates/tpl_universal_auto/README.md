# Скрытый адаптивный универсальный шаблон

`tpl_universal_auto` — служебный шаблон по умолчанию. Доступен генерации (`available=true`), скрыт из каталога и избранного (`hidden=true`). Публичные шаблоны не меняются.

Reference подготовлен из предоставленного пользователем фонового JPEG: мягкий студийный градиент без товара и надписей. Это образец света и глубины, а не фиксированный голубой фон. Цвет и окружение определяются идеей анализа; реальный товар не перекрашивается. Нейтральная палитра в authoring JSON служит заполнением общей схемы и не переносится компилятором в адаптивный prompt.

- Reference: [78af07e8-8dff-542c-81a7-248453066ac9.webp](78af07e8-8dff-542c-81a7-248453066ac9.webp), WebP 384×512, 2178 байт.
- Ключ: `templates/tpl_universal_auto/78af07e8-8dff-542c-81a7-248453066ac9.webp`.
- Asset ID: `asset_tpl_universal_auto_ref`.
- Общие правила: [recipe.json](recipe.json).
- Десять сценариев: [card-variants.json](card-variants.json).
- Миграции: `083-hidden-universal-template`, `084-hidden-universal-variants`.

Идея первой карточки берётся из актуального анализа и допускает правки. При первой генерации окончательное оформление фиксируется в snapshot серии. Последующие карточки используют собственные сценарии и тот же замысел оформления. Новые проекты получают шаблон по умолчанию; для старых без выбранного стиля он разрешается при чтении next-draft. Существующие карточки и сохранённые серии не изменяются.

Файл синхронизируется обычным backend-деплоем до запуска Liquibase. Вручную в MinIO или БД данные не загружать.
